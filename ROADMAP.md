`[ ]` not implemented -- `[no]` deliberate non-goal.

libzim's writer, so **the zim tests need `libzim` (`pip install "primarysource[zim]"`) and are skipped without it**;
everything else in the suite passes without it. A row whose only evidence is a zim test is therefore checked by the
suite only where libzim is installed.
